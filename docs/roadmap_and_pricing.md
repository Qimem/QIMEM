# Roadmap & Pricing Model

## Phased Build Plan

### Phase 1
- Refactor to true KMS.
- Implement envelope encryption.
- Introduce tenant model.
- Ship JavaScript SDK.

### Phase 2
- Secure Prompt Gateway.
- Audit logging with hash-chaining.
- Enforced zeroization in gateway.

### Phase 3
- API Key Vault.
- Scoped access tokens.

### Phase 4
- Vector encryption model.
- Advanced policy engine.

### Pro
- Usage-based encryption operations
- Secure AI gateway calls

### Enterprise
- Dedicated environment
- Compliance assistance
- SLA
- Custom deployment
