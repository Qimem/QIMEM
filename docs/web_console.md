# Web Console: Security Control Plane

## Purpose
The web console is not a demo playground. It is the operational cockpit for managing tenants, policies, and cryptographic lifecycle.

## Capabilities
- Tenant management
- Key lifecycle and rotation
- Policy configuration and crypto agility
- Audit log inspection
- API key vault management
- Usage analytics (decrypt counts, gateway calls)
- Post-quantum policy visibility

## UI Principles
- Dark mode default
- Minimal, serious, operator-first design
- Clear per-tenant separation
- Explicit key version visibility
- No cryptography demo widgets
